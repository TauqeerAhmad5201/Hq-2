# 🎮 Catch the Happy! 😊

A fun and engaging browser-based clicker game where players catch happy emoji faces before they disappear! Test your reflexes and see how high you can score in this colorful, family-friendly game.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

## 🌟 Features

- **Simple & Addictive Gameplay**: Click on happy faces as they appear on screen
- **Colorful Emojis**: Variety of cheerful emojis including 😊, 😄, 😁, 😆, 🥰, 😍, 🤩, and 🥳
- **Visual Feedback**: Satisfying confetti effects when catching emojis
- **Score Tracking**: Real-time score display to track your progress
- **Time-Limited Rounds**: 30-second game sessions for quick, exciting gameplay
- **Responsive Design**: Works smoothly across different screen sizes
- **No Dependencies**: Pure HTML, CSS, and JavaScript - no external libraries required

## 🎯 How to Play

1. Click the **"Start Game"** button to begin
2. Happy emoji faces will randomly appear in the game area
3. **Click on the emojis** before they disappear (you have 2 seconds per emoji!)
4. Each successful catch adds 1 point to your score
5. The game lasts for **30 seconds** - catch as many as you can!
6. When time's up, see your final score and play again

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/TauqeerAhmad5201/Hq-2.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Hq-2
   ```

3. Open `index.html` in your web browser:
   ```bash
   # On macOS
   open index.html

   # On Linux
   xdg-open index.html

   # On Windows
   start index.html
   ```

   Or simply double-click the `index.html` file to open it in your default browser.

## 🎨 Technical Details

### Game Mechanics

- **Spawn Rate**: New emojis appear every 600ms
- **Emoji Lifetime**: Each emoji stays on screen for 2 seconds
- **Game Duration**: 30 seconds per round
- **Scoring**: +1 point per emoji caught

### Styling

- Playful font family ("Comic Sans MS", "Chalkboard SE") for a fun atmosphere
- Vibrant color palette with coral red (#ff6b6b), turquoise (#4ecdc4), and yellow (#ffd93d)
- Smooth CSS animations for emoji pop-in effects
- Confetti particle system for visual feedback
